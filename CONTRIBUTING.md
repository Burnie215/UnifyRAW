# Contributing to UnifyRAW

Thank you for your interest. UnifyRAW is **open source, but not open contribution**.

## What is welcome

- **Bug reports**, with steps to reproduce, the source type and the browser:
  [report a bug](https://github.com/Burnie215/UnifyRAW/issues/new?template=bug_report.yml).
- **Feature requests and ideas**, including sources you would like to see:
  [request a feature](https://github.com/Burnie215/UnifyRAW/issues/new?template=feature_request.yml).
- **Questions**, and a thumbs-up on existing issues instead of a duplicate.

## What is not accepted

**Pull requests and other code contributions are not accepted** and will be closed
without review. This is not about the quality of your work: all code in UnifyRAW
comes from its one author, so that the whole code base stays under a single copyright
holder and its licensing can be decided in one place.

For the same reason, please do not paste code or patches into issues. Describe the
problem or the idea in words; if it fits, it will be implemented.

## Using the code

You are free to use, study, modify and share UnifyRAW under the terms of the
[GNU AGPL v3](LICENSE) (`AGPL-3.0-only`) - including in your own fork. If you run a
modified version as a network service, the AGPL requires you to offer its source code
to the users of that service.

## Security issues

Please do not open a public issue for a security problem. Write to the contact address
in the app (*Info > Imprint*) instead.
